# Moncho Park

**Moncho Park** is a web application for the San Ramon Skatepark community.  
The project provides a modern website where visitors can explore the park, learn about events, contact the team, and interact with the skate community.

The project is built with **Node.js, Express, EJS, and PostgreSQL**, following a modular structure for scalability and maintainability.

# Description

Moncho Park is designed to represent the **San Ramon Skatepark experience online**.

The website allows users to:

- View information about the skatepark
- Explore events and activities
- Contact the park team
- Navigate through a modern responsive interface
- Experience fast performance powered by Node.js

The project uses **server-side rendering with EJS** and follows a clean MVC-like structure for routes, views, and public assets.

---

# Tech Stack

- **Node.js**
- **Express.js**
- **EJS Template Engine**
- **PostgreSQL**
- **Passport.js Authentication**
- **JWT Authentication**
- **Nodemailer (Email service)**
- **Express Sessions**
- **bcryptjs (Password encryption)**
